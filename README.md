# 性行为同意协议生成器

一个用于生成性行为同意协议的Web应用，帮助成年人明确双方意愿并记录协议内容。

## 功能特性

- **协议创建**：提供5种不同风格的协议模板，包括标准版、详细版、简约版、健康版和隐私版
- **协议签署**：支持双方电子签名功能，确保协议的真实性
- **协议管理**：查看所有已创建的协议，包括草稿和已签署状态
- **PDF导出**：将协议导出为PDF格式，便于保存和打印

## 使用方法

1. **创建协议**：
   - 填写协议标题
   - 输入双方姓名和身份证号
   - 选择或自定义协议内容
2. **签署协议**：
   - 双方分别进行电子签名
   - 签名完成后协议状态变为"已签署"
3. **管理协议**：
   - 查看所有协议列表
   - 导出已签署协议为PDF

## 技术栈

- **前端框架**：React + TypeScript
- **UI库**：Tailwind CSS
- **签名功能**：react-signature-canvas
- **PDF生成**：jsPDF
- **状态管理**：React Hooks
- **本地存储**：localStorage

## 数据安全

所有协议数据仅存储在浏览器本地(localStorage)，不会上传到任何服务器。
